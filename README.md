# End-to-End Customer Shopping Behavior Analytics

This project delivers a comprehensive, end-to-end data analytics solution using **SQL, Python, and Tableau**. It analyzes retail customer shopping trends to uncover key insights regarding product performance, purchase behavior, and subscription-driven revenue.

## 🛠️ Tech Stack & Tools Used
* **Database Management:** MySQL (Data querying, aggregation, and performance optimization)
* **Programming & Analytics:** Python (Pandas, Exploratory Data Analysis in Google Colab)
* **Data Visualization:** Tableau Public (Interactive Business Dashboard)
* **Data Inspection:** Microsoft Excel (Initial data quality assessment)


## 🏗️ Data Architecture & Project Pipeline

1. **Data Ingestion & Inspection:** Sourced and reviewed the raw shopping dataset via Excel to check headers and structure.
2. **Exploratory Data Analysis (Python):** Utilized Pandas in Google Colab to inspect data types, shapes, and verify that there are zero missing values.
3. **Database Transformation (SQL):** Imported raw data into MySQL and wrote optimized aggregate queries to transform raw logs into high-level business metrics.
4. **Business Intelligence (Tableau):** Connected the clean data to Tableau to build an executive-facing interactive dashboard.

## 📂 Project Files Covered
* `customer_analytics_queries.sql`: Contains the clean backend SQL queries used for data processing.
* `Customer_Shopping_Trends_Analysis.ipynb`: The Python notebook detailing the statistical exploration and charts.
* `shopping_trends_updated.csv`: The foundational retail dataset (3,900 rows).
